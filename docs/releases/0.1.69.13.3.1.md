# VIBE BETA 0.1.69.13.3.1

Released: 2026-09-16

## Summary

This documentation release records the poll and verification work delivered in the 0.1.69.13.3 line and establishes a versioned release-notes process for future changes.

## Included functionality

### Timed homepage polls

- Administrators can create poll drafts with a question and two to six unique answers.
- Draft polls can be prepared in advance and switched live or offline from the Admin area.
- Only one poll can be live at a time. A live poll runs for 72 hours.
- While live, the poll is displayed above the first post on the homepage. If there is no live poll, no poll card is shown.
- Signed-in members can select an answer. Their vote can be changed while the poll is live.
- The homepage shows answer totals, percentages, and small voter avatars where available.
- Expired polls are removed from the homepage and remain available to administrators for review and results.
- Poll-draft validation is rendered in the form instead of surfacing as an uncaught runtime error.

### Profile verification

- Administrators can verify or remove verification from a member in Admin user management.
- Verification is a status only. It grants no additional permissions.
- The reusable badge component supports multiple badges, so an account can show both Admin and Verified status and can accept future statuses.
- Verified badges are shown wherever the profile name is rendered in the updated product surfaces, including profiles, directory and suggestion cards, posts, comments, and Admin user management.
- A newly verified member receives a celebratory VIBE Team direct message in both German and English.
- Verification changes return immediately. The notification is sent after the response and retried once if the first delivery attempt fails, so a temporary messaging failure does not undo the verification.

## Documentation process

Every release now receives an English Markdown file in `docs/releases/` named after the release version. The root `DOCUMENTATION.md` describes the current architecture, data model, development workflow, and release process.

- TypeScript: `tsc --noEmit`
