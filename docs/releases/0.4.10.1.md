# VIBE 0.4.10.1 - Quick settings auto-close

Release date: 2026-10-09. Local development step; not deployed.

- Quick Settings now closes after theme and language actions finish saving or applying locally.
- If an action stays pending, the orb closes after a three-second fallback timer.
- Settings and Support navigation close the orb before leaving the page, so returning from Settings keeps the orb closed.
- Route changes reset the Quick Settings panel to closed and clear pending auto-close timers.

Web development version and changelog are 0.4.10.1. Native APK/EXE downloads remain pinned to accepted 0.4.1 artifacts.
