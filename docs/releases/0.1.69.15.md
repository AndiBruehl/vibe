# VIBE BETA 0.1.69.15

## Video posts

- Posts can now contain MP4, WebM, and MOV videos alongside existing image formats.
- The composer supports drag and drop, mixed media galleries, reordering, removal, and local drafts for video posts.
- Videos are played with native browser controls in post detail views and feeds. Profile, Search, and Browse grids recognise video cover media.

## Upload fallback

- Profile image and post media uploads automatically receive a safe, short filename before storage, avoiding Pinata filename length failures.
- Upload errors now explain whether the file type, size, parsing, or storage step caused the failure.

## Data and safety

- Each post stores a media type alongside every media URL, so playback does not depend on filenames or gateway URL extensions.
- Signed post upload URLs accept supported video formats up to 100 MB. Image limits remain 25 MB.
