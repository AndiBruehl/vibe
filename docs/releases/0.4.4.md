# VIBE 0.4.4 - Update integrity

Local preparation, 2026-10-09. Not pushed or deployed.

- Added SHA-256 and byte-size metadata for the current Android APK and Windows EXE in `public/releases/latest.json`.
- Release discovery now reuses only artifacts whose version already has committed integrity metadata, so an unknown uploaded APK or EXE is ignored until the manifest is updated intentionally.
- Android update downloads validate the expected APK byte size before opening the installer and keep the browser-download recovery path for failed downloads, failed installs or integrity mismatch.
- Desktop update notices include the expected SHA-256 value for manual verification before running the installer.
- Web development version and changelog are 0.4.4. Published APK/EXE metadata and native versions remain 0.4.1; no new installer was built.

Detached metadata signing is still open. This local step adds committed checksum and size verification, but it does not provision a signing key or attach a cryptographic manifest signature.
