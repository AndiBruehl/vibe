# VIBE 0.5.0.4 — Android update bootstrap

Date: 2026-10-12

Android no longer waits for a stored mobile token before checking for updates. This keeps the update prompt available on the native login screen and when an old session cannot open the web bridge.

The Android release manifest lookup now tries the Vercel-hosted `/releases/latest.json` first and uses GitHub Raw as a fallback, so devices that can reach the app host do not depend on GitHub Raw for update discovery.

Validation:

- Android release readiness tests
- Release integrity/signature/fallback tests
- Android auth tests
- Android TypeScript
- Web TypeScript
