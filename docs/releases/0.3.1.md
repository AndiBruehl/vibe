# 0.3.1 - Public profile polish

Date: 2026-10-06. Web release; native APK/EXE artifacts remain at their actual published version.

- Public guest profiles now show safe profile links when the owner has not hidden them.
- Public guest profiles now show shoutouts, filtered to non-private target profiles.
- Visible milestone badges and profile counts are shown on guest profile headers.
- The public profile header keeps personalization from 0.3.0 while staying read-only.
- Guests get a clear Join to interact action near public posts instead of follow, message, or comment controls.
- Profile counts and optional sections fail softly, so public profile headers remain readable if one secondary query is temporarily unavailable.

Validation: TypeScript and targeted ESLint passed for the public profile page.
