# VIBE 0.1.86

Released: 2026-09-28

- Added shared pinned messages to direct and group conversations.
- Members can pin up to three messages, browse them with previous and next arrows, and jump to the original message.
- The compact trash control removes one pin only; it never deletes the original message.
- The Quick settings orb moves dynamically below the visible pin strip so it cannot cover pin controls.
- Added membership checks, server-side pin limits, cleanup for message, conversation, and account deletion, plus multilingual recovery feedback.
- Added a compatibility fallback so conversations remain readable while a local or rolling Prisma client has not loaded the new `ConversationPin` delegate yet.

Validation: Prisma client generated and schema synchronized with Atlas. TypeScript passes, the affected code passes its applicable checks, and the complete Next.js production build passes.
