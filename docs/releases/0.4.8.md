# VIBE 0.4.8 - Signature-aware update checks

Release date: 2026-10-09. Local development step; not deployed.

- The release endpoint now returns the detached signature envelope beside the Android and Windows release metadata.
- Android update discovery now ignores releases that do not include version, download URL, SHA-256 and byte size metadata.
- Desktop update checks now reject malformed SHA-256 or byte-size metadata before showing an update prompt, and the update dialog includes both checksum and size evidence.

This is the runtime validation step before full cryptographic enforcement. The current signature envelope is still an unsigned public example, so installed wrappers must not be marked production-accepted until a real detached signature and public-key verification path are published with rebuilt artifacts.

Web development version and changelog are 0.4.8. Published APK/EXE metadata and native versions remain 0.4.1; no new installer was built.
