# VIBE 0.4.10.6 - Quick settings feedback-then-close

Release date: 2026-10-09. Local development step; not deployed.

- Quick Settings now keeps the panel open while the green saved pill is visible.
- The saved/failed pill fades out first; only after it disappears does the panel run its reverse close animation.
- Save success/failure cancels the generic auto-close timer so the panel cannot close before feedback is finished.

Web development version and changelog are 0.4.10.6. Native APK/EXE downloads remain pinned to accepted 0.4.1 artifacts.
