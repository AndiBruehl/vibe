# VIBE 0.5.0.6 — Android login compatibility and Windows installer

Date: 2026-10-12

This APK keeps the conflict-safe Android package ID `com.vibe.social.beta`, but restores the mobile auth callback to `vibe://auth` so Google sign-in works against the currently deployed Vercel backend.

It keeps the update check before login and the Vercel-first release manifest lookup from the previous Android fixes.

Validation:

- Android release build
- Release integrity/signature/fallback tests
- Mobile login redirect tests
- Android auth tests
- Android TypeScript
- Web TypeScript

## Native artifacts

- Android APK: `android-app/dist/Vibe-BETA-0.5.0.6.apk`
- Windows installer: `electron-app/dist/Vibe-Setup-BETA-0.5.0.6-x64.exe`
- `public/releases/latest.json` points both Android and Windows to the rebuilt 0.5.0.6 beta artifacts.
- The Android beta keeps package ID `com.vibe.social.beta` and uses the live-compatible `vibe://auth` Google login callback.
- The Windows installer embeds app version `0.5.0-beta.6`, which VIBE displays and compares as `0.5.0.6`.
- Detached release signing still uses the local placeholder envelope until a real signing key is provisioned.
