# VIBE 0.4.10.3 - Quick settings open auto-close

Release date: 2026-10-09. Local development step; not deployed.

- Opening Quick Settings now starts the three-second auto-close timer immediately, even if no theme or language option is selected.
- Closing the orb manually clears the pending auto-close timer.
- Theme, language, Settings and Support actions keep the existing immediate close behavior from 0.4.10.1 and the timer guards from 0.4.10.2.

Web development version and changelog are 0.4.10.3. Native APK/EXE downloads remain pinned to accepted 0.4.1 artifacts.
