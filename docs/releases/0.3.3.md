# 0.3.3 - Public SEO and share previews

Date: 2026-10-06. Web release; native APK/EXE artifacts remain at their actual published version.

- Public guest profile pages now generate stable titles, descriptions, canonical URLs and OpenGraph/Twitter previews.
- Public guest post pages now generate stable titles, descriptions, canonical URLs and OpenGraph/Twitter previews.
- Profile previews use only public profile fields and avatar images.
- Post previews use only public post fields and the first public media image.
- Missing, archived, private-author or invalid public pages return noindex metadata.

Validation: TypeScript and targeted ESLint passed for the metadata helper and public profile/post pages.
