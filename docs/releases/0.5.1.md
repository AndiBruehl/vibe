# VIBE 0.5.1 — Native update integrity and acceptance prep

Date: 2026-10-23
Status: local debug candidate; not published.

Android now accepts update manifests only when the version, pinned HTTPS APK URL, SHA-256 and byte size are valid. Before opening the installer, it checks the downloaded file size and hashes the file in 1 MiB chunks. A mismatch deletes the APK and blocks the browser fallback.

Desktop update discovery applies the same strict metadata shape and only accepts the pinned HTTPS VIBE installer URL. The update prompt continues to show the expected checksum and byte size. Release integrity checks compare both candidate artifacts with their recorded local metadata.

The Android update check still runs before login and tries the Vercel manifest before GitHub Raw. A clean install and launch smoke test passed on an Android 15 emulator. Provider login and installed-update acceptance remain open, and the published manifest remains on 0.5.0.6.

## Manual device acceptance still open

Real Android and Windows sessions must confirm Google/Discord consent, cancellation, retry and restart during provider handoff. Update acceptance also needs an older installed build to discover the 0.5.1 manifest, download the candidate and show the expected size/hash behavior. A bad-hash APK must be blocked. This local candidate is not visible to installed apps until its manifest is published.

The detached release-metadata signature remains unprovisioned; this work prepares debug beta candidates only.
