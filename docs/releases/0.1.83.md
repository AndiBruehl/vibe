# VIBE 0.1.83

Released: 2026-09-26

- Added a localized Edited marker and expandable text-version history for edited posts.
- Previous post text is saved safely before a changed version replaces it.
- Added message editing for senders during the first 10 minutes after sending, without changing conversation activity counters.
- Edited messages show a localized Edited marker while retaining their original send time.
- Refined message actions with VIBE-styled circular Save and Cancel controls, unframed emoji reactions, and `YY-MM-DD HH:MM` read-status timestamps.
- If an edit cannot be saved, the entered text remains open with a localized retry message.
- Added confirmed sender-only message deletion. Deleting a message also removes its reactions and any unread-message notification derived from it.
- Added replies to individual messages with a quoted sender and text preview. Selecting the preview jumps back to the source message.
- If a replied-to message is deleted, replies retain a localized Deleted message fallback instead of breaking.

Validation: Prisma schema applied to Atlas, Prisma client generated, TypeScript and focused ESLint checks pass.
