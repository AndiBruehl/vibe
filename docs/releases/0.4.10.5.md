# VIBE 0.4.10.5 - Quick settings hover pause

Release date: 2026-10-09. Local development step; not deployed.

- Quick Settings no longer starts or keeps the auto-close timer while the pointer or keyboard focus is inside the orb.
- Re-entering the orb clears any running auto-close timer.
- Leaving hover/focus starts a fresh three-second timer, and the existing reverse close animation still runs before unmount.

Web development version and changelog are 0.4.10.5. Native APK/EXE downloads remain pinned to accepted 0.4.1 artifacts.
