# VIBE BETA 0.1.71

## Account post drafts

- Added New post and Drafts tabs to Create, including the account draft count.
- Added Save draft for incomplete posts, with persistent images/videos, description, topics, and tagged profiles.
- Added draft previews, modification dates, reopening, updating, and deletion.
- Scoped all draft queries and mutations to the signed-in account.
- Publishing removes the source draft transactionally with post creation.
- Added English/German labels and recoverable save/delete error messages.
- Retained unsaved editor contents while switching tabs.
- Added safe fallbacks for unavailable draft data, missing tagged profiles, malformed legacy arrays, invalid dates, and stale delete requests.

## Deployment

- Regenerate Prisma Client for the new PostDraft model before starting the server.
- This is a local web update; native installer builds and production deployment are separate.
- Web version labels include the release date in `YYYY-MM-DD` format; desktop and Android retain version numbers only.
