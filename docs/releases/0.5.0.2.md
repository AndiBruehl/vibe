# VIBE 0.5.0.2 🛡️ — Android login callback runtime fix

Release date: 2026-10-12. Local development step; not deployed.

## Problem

The Android APK could open Google sign-in and return to VIBE, but then showed `undefined is not a function` on the native login screen. The failing step was the mobile token confirmation request after the OAuth callback.

## Root cause

The APK used `AbortSignal.timeout(15000)` for the `/api/mobile/profile` verification request. That API is not available in some React Native Android runtimes, so the callback failed before VIBE could store the mobile token and open the WebView session.

## Changes

- Replaced `AbortSignal.timeout` with a React Native-compatible `AbortController` timeout helper.
- Kept the 15-second timeout behavior for mobile token verification.
- Added regression coverage to prevent reintroducing `AbortSignal.timeout` in the APK login path.
- Prepared Android metadata for 0.5.0.2 / versionCode 102.

## Still true

Android APK metadata now points to the rebuilt 0.5.0.2 artifact. Windows metadata remains pinned to accepted 0.4.1 until rebuilt, signed and manually accepted.
