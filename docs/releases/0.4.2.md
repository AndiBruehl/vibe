# VIBE 0.4.2 — Android debug-keystore hygiene

Local preparation, 2026-10-09. Not pushed or deployed.

- Removed the tracked Android debug keystore and explicit standard debug passwords; ignored keystore file extensions.
- Android debug and beta APK builds still use Android tooling's debug signing flow. The local debug key is generated outside the repository by the Android tooling instead of being committed.
- Production signing, certificate migration and GitGuardian closure remain separate release work.
- Web development version and changelog are 0.4.2. Published APK/EXE metadata and native versions remain 0.4.1; no new installer was built.

The old debug key is still present in Git history and cannot be made private by this deletion. Existing beta artifacts remain debug/beta artifacts; this change only removes the checked-in copy from the current tree.
