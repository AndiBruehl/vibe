# 0.3.2 - Public post detail polish

Date: 2026-10-06. Web release; native APK/EXE artifacts remain at their actual published version.

- Public post detail pages for logged-out visitors now use a fuller two-column detail layout on wide screens.
- Author identity, compact badges, post date, like count and optional public location are visible without enabling member actions.
- Guests see clear Join VIBE guidance instead of like, comment, follow, message or bookmark controls.
- Missing media or missing text uses readable fallback copy rather than an empty card.
- Public-post access still requires a non-archived post from a public author profile.

Validation: TypeScript and targeted ESLint passed for the public post detail page and public guest data selectors.
