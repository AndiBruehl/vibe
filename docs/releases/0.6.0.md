# VIBE 0.6.0 — Tagged posts in profile feeds

Date: 2026-10-28

Status: Web release candidate.

Posts and images that explicitly tag a profile, link to it with an @mention in the description, or mention it in a comment appear in the regular profile grid as well as the Tagged section. The normal grid includes them in its post count and sorting. Entries link to the original post and show its media, description, topics, and date.

The feed follows the original post's visibility rules. Archived posts and posts from blocked profiles are hidden. Posts by private profiles are shown to the author and followers who can access them. Guests see only posts whose authors are explicitly public. If a source query fails, successful sources remain visible with a partial-results message; failures during visibility checks fail closed. If tagged data is unavailable, authored posts still display with a status message.

The candidate includes the account-deletion flow prepared for 0.5.5. Protected administrator and system accounts cannot self-delete. Device-local draft cleanup is best effort; server-side deletion remains authoritative. No native APK or EXE version changed.
