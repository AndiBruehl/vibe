# VIBE BETA 0.1.69.14.6

Released: 2026-09-16

## Activity notification preferences

Members can now choose which activity types contribute to their Activity counter and in-app activity notifications:

- Likes
- Comments and replies
- Mentions
- Follow requests
- Admin updates

Preferences are stored on the profile and default to enabled, preserving the existing experience for current members. The activity-status service filters both its counts and newest activity timestamp before returning a result to web navigation and in-app polling.

## Related fixes

- Opening `/activity` marks the activity inbox as read and clears the Activity badge in desktop and mobile navigation without a page reload.
- Prisma development logging now records errors without printing every database query.
