# VIBE 0.4.0 — Guest-to-account onboarding rebuilt

Release date: 2026-10-08

This rebuild starts from the 0.3.10 production baseline. It keeps the protected member app and guest/public app separated.

- Rebuilt the Join page as a clear account-onboarding step after public browsing.
- Added the explicit Google/Discord account warning above the sign-in section.
- Added a required acknowledgement checkbox before any Join-page sign-in button can start.
- Explained that Google or Discord can create the first account, and the other provider must be linked later from Settings → Sign-in methods to stay on the same VIBE profile.
- Added read-only guest sorting for public posts by newest, oldest or most liked.
- `/` redirects to `/home`; authentication errors return to `/join`. Authenticated `/home` and `/profiles` remain in the protected app.
- Fixed Discord issuer validation and removed temporary OAuth debug output.
- Filtered orphaned follow/follow-request records from web and mobile activity lists.
- Release lookup falls back to the bundled manifest on GitHub outages, rate limits, invalid responses or timeouts; one platform can still update if the other fails.

Validation:

- `node --test scripts\test-guest-access.cjs scripts\test-guest-settings.cjs`
- `node node_modules\typescript\bin\tsc --noEmit`
- targeted ESLint for the changed auth, guest and release files
- Production web build (`next build --webpack`) passed on 2026-10-08, including TypeScript and generation of all 58 static pages.
- local route checks for anonymous guest rewrites and authenticated protected passthrough

Manual acceptance before production: sign in with a real Google account, sign in with a real Discord account, confirm authenticated `/home` shows protected posts, confirm authenticated `/profiles` shows protected profiles, confirm guest `/home` and `/profiles` stay read-only.

Native beta builds completed locally on 2026-10-08:

- Android: `android-app/dist/Vibe-BETA-0.4.0.apk`, versionName 0.4.0, versionCode 93, verified with aapt and apksigner. Uses the existing development signing key.
- Windows: `electron-app/dist/Vibe-Setup-BETA-0.4.0-x64.exe`, packaged version 0.4.0; startup code and offline recovery assets verified. Unsigned beta installer.
- `public/releases/latest.json` points to the matching artifacts included in the release commit. Download URLs become available when that commit reaches GitHub main.
- 30 guest/auth tests, 7 Android session/callback tests and 9 desktop recovery/security tests passed. Android TypeScript and ESLint passed; targeted web ESLint has no errors (six pre-existing unused-disable warnings in the activity page).
- Final pre-push suite: 61 web tests passed, including account deletion/linking, last-provider protection and five download-fallback scenarios.
- Real-device installation and OAuth round trips remain manual acceptance checks. The APK uses the production API; local web changes require deployment to become available there.
