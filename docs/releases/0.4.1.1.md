# VIBE 0.4.1.1 — Caption links and mention selection

Release date: 2026-10-09.

- HTTP/HTTPS and www addresses in post descriptions become clickable links; mentions remain profile links. URLs containing an @ are not split into mentions, and email addresses remain text.
- Links permit only HTTP/HTTPS, reject embedded credentials, preserve punctuation and open with noopener/noreferrer. Rendering uses React text, not raw HTML.
- Fixed the controlled caption editor: suggestion selection now updates the same state used by typing, autosave and submission. This inserts a text mention without adding a profile tag. Shared comment/message editors receive the same wiring fix.
- Search has an eight-second timeout, rejects malformed responses and ignores stale responses. Text remains editable when suggestions are unavailable. Pointer selection retains textarea focus.
- Web version and changelog: 0.4.1.1. Native installer versions and download metadata remain 0.4.1: installed wrappers receive the updated website after deployment; no native code changed.

Validation: all 23 caption/selection/fallback and guest regression tests passed; TypeScript and the Webpack production build passed. Targeted ESLint passed with no errors and three existing image-optimization warnings. No live OAuth or native-device acceptance tests were performed for this web hotfix.
