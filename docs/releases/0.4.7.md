# VIBE 0.4.7 - Detached release signature format

Release date: 2026-10-09. Local development step; not deployed.

- Added `scripts/release-signature.cjs` with Ed25519 signature envelope creation and verification helpers for the canonical native release metadata payload.
- Added `public/releases/latest.sig.example.json` as the public detached-signature envelope shape. It intentionally contains no real signature because the private release key must stay outside the repository.
- Added regression coverage for valid in-memory signatures, tampered manifest metadata and missing signature fields.

This prepares detached manifest signatures without storing signing secrets in the tree. Runtime enforcement in Android/Desktop update checks, real key provisioning and signed rebuilt native artifacts remain separate work.

Web development version and changelog are 0.4.7. Published APK/EXE metadata and native versions remain 0.4.1; no new installer was built.
