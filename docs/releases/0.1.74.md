# VIBE 0.1.74 — Profile section visibility

Released: 2026-09-23

- Added per-profile visibility controls for links, shoutouts, pinned posts, highlights, topics, and archive navigation.
- Added an immediate Settings preview that shows the visitor-facing profile structure.
- Hiding a section never deletes its data; it can be restored with the same switch.
- Added compatibility fallbacks so older MongoDB profile documents stay fully visible until their owner makes a choice.
