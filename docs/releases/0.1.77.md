# VIBE 0.1.77

## Profile look import and export

- Export every saved profile look as a portable, human-readable `.json` file.
- Import a compatible VIBE profile-look JSON file directly into saved looks.
- Limit imports to six saved looks, matching the existing preset limit.
- Export only appearance fields: layout, header background, profile-image frame, and accent colors.
- Validate the file shape in the browser and normalize every accepted appearance field again on the server.
- Ignore identity, roles, badges, profile links, and all other non-appearance data.
- Explain import failures in plain language for malformed JSON, incompatible files, empty or oversized files, a full saved-look limit, and temporary save failures.

## Validation

- `tsc --noEmit`
- `git diff --check`
