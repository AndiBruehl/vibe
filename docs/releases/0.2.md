# VIBE 0.2

Released: 2026-09-29

- Added voluntary location sharing with approximate and more precise options.
- Added manual location selection by map tap or coordinates when GPS is unavailable.
- Integrated interactive Leaflet/OpenStreetMap maps for members and post coordinates, with grouped markers for shared positions.
- Maps follow the active light/dark/system theme, including map tiles, markers, popups and touch-sized zoom controls.
- Added fallback behavior for unavailable GPS, empty map tiles, invalid addresses, and manual coordinate entry. Saved address labels are restored when settings reopen.
- All free-form place names use the same best-match geocoding flow; temporary geocoder outages fall back to map tapping or coordinates with a clear message.
- Added the internal VIBE member map for opted-in profiles.
- Members can update or stop location sharing at any time.
- Existing posts can be edited with an optional Where am I location marker.
- Post locations are clickable and open an OpenStreetMap view.
- Home now shows the latest version beside Changelog.
- Home shows the release date beside Changelog (2026-09-29).
- Location autosave ignores stale responses and does not save again merely because a response updates the inputs. Failed searches and failed storage preserve the previous saved location.
- New Android and Windows packages carry internal version 0.2.0; Android versionCode is 91.

Validation: production web build, TypeScript, focused ESLint, six location-route tests, nine desktop tests, seven Android tests and Android typecheck passed. APK and NSIS builds passed. Live geocoding returned results for Hell and Schillerstraße 66 Erfurt.

Distribution status: approved for publication as beta test packages, following the existing distribution workflow. The Windows installer is unsigned; Android uses the existing development signing key. These are not production-signed packages.
