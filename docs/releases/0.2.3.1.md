# 0.2.3.1 — Account and sign-in bugfix

Date: 2026-10-05. Local bugfix release.

- Admin profile deletion removes provider identities, password credentials and pending login proofs.
- Deleted profiles revoke active sessions.
- Expired and orphaned Google or Discord identities recover safely.
- Google and Discord link only through an explicit authenticated Settings action.
- Admin-only notification settings are hidden from regular profiles.
- Duplicate guest entry actions were removed.

Verification: 18 authentication and fallback tests, TypeScript and targeted ESLint passed. Native packages were not rebuilt.
