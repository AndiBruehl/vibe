# 0.3.5 - Public comments read-only

Date: 2026-10-06. Web release; native APK/EXE artifacts remain at their actual published version.

- Logged-out visitors can read comments and replies on public post detail pages.
- Guest comments render with public author identity and compact badges only.
- Like, reply, report, edit and delete controls stay hidden for guests.
- Comment queries select public author fields only and avoid mutation state.
- Comment loading fails softly so the post remains visible if comments are temporarily unavailable.

Validation: guest-access tests include public comment selection safeguards. TypeScript, targeted ESLint and diff whitespace checks passed.
