# VIBE 0.4.11 — Quick Settings stabilization and signing gates

Release date: 2026-10-09. Local development step; not deployed.

## Quick Settings behavior

- Theme and language actions now stop the generic three-second auto-close timer while the save is running.
- Successful saves show the localized green Saved/Gespeichert pill before any panel close starts.
- The feedback pill fades out first; then the Quick Settings panel closes with its reverse exit animation.
- Manual close and fresh open clear stale saved/failed/working feedback, so old Saved/Gespeichert text cannot reappear.
- Hover/focus still pauses the generic open-without-action auto-close timer without blocking action-completion close.
- Route refresh after a language save no longer clears the feedback fade-out timer or leaves the orb open.

## Native signing gates

- Added the signing decision record in [native-signing-0.4.11](../acceptance/native-signing-0.4.11.md).
- Documented the current beta/debug signing boundary for Android and the unsigned-beta boundary for Windows.
- Defined release gates before any production-signed native artifact: protected signing material outside the repository, certificate migration decision, GitGuardian evidence, rebuilt artifact hashes, detached metadata signature and installed-device acceptance.

This does not create or store signing keys. No production signing material was added to the repository.

Web development version and changelog are 0.4.11. Native package metadata remains prepared for 0.4.9 rebuilds, while published APK/EXE downloads remain pinned to accepted 0.4.1 artifacts until rebuilt and manually accepted.
