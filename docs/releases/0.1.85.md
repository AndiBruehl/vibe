# VIBE 0.1.85

Released: 2026-09-28

- Added private saved messages for direct and group conversations.
- Saved messages are searchable, grouped by conversation, and link back to their original message.
- Saved records are removed when their message, conversation, or account is deleted.
- Added localized recovery and retry feedback when saved-message storage is temporarily unavailable. Chats remain available and failed save actions restore their previous state.
- Published matching Windows and Android 0.1.85 release artifacts.

Validation: Prisma schema applied to Atlas, Prisma client generated, TypeScript and focused ESLint checks pass. Windows and Android artifacts are rebuilt and verified for this release.
