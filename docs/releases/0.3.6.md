# VIBE 0.3.6 — Guest conversion polish

Release date: 2026-10-06

- Added a shared guest join prompt across public posts, public profiles, profile pages and post details.
- Guest calls-to-action now use one consistent account-entry path without adding member-only controls.
- Guest conversion copy explains which actions require an account while public reading remains available.
- Kept restricted guest access read-only: no posting, commenting, liking, following, messaging or saving controls are exposed to guests.
