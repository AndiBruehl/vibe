# VIBE 0.5.0.5 — Android conflict-safe beta

Date: 2026-10-12

This APK uses the Android package ID `com.vibe.social.beta` so it can install even when Android still holds a hidden or cross-user remnant of the old `com.vibe.social` package.

The mobile sign-in callback uses `vibebeta://auth`. The backend accepts both `vibe://auth` and `vibebeta://auth`, so the conflict-safe APK does not depend on the old app scheme.

Validation:

- Android release build
- Release integrity/signature/fallback tests
- Mobile login redirect tests
- Android auth tests
- Android TypeScript
- Web TypeScript
