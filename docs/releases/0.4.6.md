# VIBE 0.4.6 - Release manifest signing prep

Release date: 2026-10-09. Local development step; not deployed.

- Added `scripts/build-release-signing-payload.cjs`, which produces a deterministic canonical payload for the APK/EXE release metadata.
- The payload covers the platform name, version, download URL, SHA-256 digest and byte size for each native artifact, plus the release name and payload schema.
- Added regression coverage so incomplete native metadata is rejected before a signing payload can be produced.

This does not add a private signing key or a detached production signature. The signing key must stay outside the repository, and the final signature should be attached only when rebuilt native artifacts and their metadata are ready.

Web development version and changelog are 0.4.6. Published APK/EXE metadata and native versions remain 0.4.1; no new installer was built.
