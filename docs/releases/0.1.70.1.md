# VIBE BETA 0.1.70.1

## Video stories

- Sharing a video post to a story now stores its media type, so the story viewer renders a playable video instead of an image placeholder.
- Video story slides autoplay muted when opened, with a localized mute/unmute control.
- Holding the story with the pointer pauses the slide; releasing resumes playback and the story timer.

## Topic video posts

- Topic feeds now select and pass each post's `mediaTypes` metadata to the shared post carousel, so video posts render with the native video player instead of an empty image area.

## Shared video posts

- Shared posts in conversations now inspect the post media type and render videos with native controls, while image shares keep the existing preview.
