# VIBE BETA 0.1.69.14

Released: 2026-09-16

## Saved profile looks

Members can now save complete profile-personalization presets from Settings.

- A saved look includes the header layout, header background mode, image or color/gradient values, header text color, profile-image frame, frame direction, and profile accent color.
- Each look has a member-defined name. Saving the same name replaces that member's saved values.
- Up to six named looks can be retained per profile.
- Settings displays a compact public-profile preview before a look is saved.
- Saved looks can be applied immediately, deleted, or used to replace a saved configuration.
- A full reset restores the standard layout, no header background, white header text, default orange profile accent, and the default single-color avatar frame.
- All preset operations are scoped to the signed-in profile and are revalidated for both the owner and public profile routes.

## Storage

The `ProfileAppearancePreset` MongoDB collection stores saved looks. It has a compound unique index for a profile and preset name, plus a profile/update-time index for loading the current member's presets efficiently.
