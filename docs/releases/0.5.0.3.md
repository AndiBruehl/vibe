# VIBE 0.5.0.3 🛡️ — Android update prompt before login fix

Release date: 2026-10-12. Local development step; Android APK rebuilt and published.

## Problem

The APK update check only ran after a stored mobile token existed. If an installed APK was stuck on the native login screen because login callback handling failed, it never checked the release manifest and therefore never showed the update prompt.

## Changes

- Start Android update discovery on app launch, independent of `mobileToken`.
- Render the update prompt even on the native login screen.
- Keep the existing SHA-256 and byte-size validation before APK install.
- Added regression coverage so update discovery is not gated by the stored mobile token.

## Published artifact metadata

- Android points to `android-app/dist/Vibe-BETA-0.5.0.3.apk`.
- Windows remains pinned to accepted 0.4.1 until rebuilt, signed and manually accepted.
- The detached signature is still an unsigned placeholder until production signing material exists.
