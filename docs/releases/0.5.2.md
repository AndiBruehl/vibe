# VIBE 0.5.2 — VIBE Reflex

Date: 2026-10-25
Status: local web release. Android and Windows remain at local 0.5.1 debug candidates.

The Games hub now has a VIBE-styled game library with previews and dedicated detail pages. VIBE Reflex is playable as a five-round reaction test: wait for the randomly timed green signal, tap or press Space, and replay a round after a false start. A completed run shows its average and fastest response time; results are not persisted or ranked. VIBE Trail, VIBE Stack, and VIBE Glide are preview-only future games.

VIBE Trail, VIBE Stack, VIBE Glide, and leaderboards remain unversioned future plans in the TODO.
