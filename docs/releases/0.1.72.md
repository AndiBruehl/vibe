# VIBE BETA 0.1.72

## Pinned profile posts

- Members pin or unpin up to three of their own public posts directly on each post tile or in its detail view.
- Pinned posts appear before the regular profile feed for every permitted viewer.
- Desktop uses three equal post tiles. On mobile, the first two occupy a row and a third pin spans the row below.
- Pinning and unpinning is available only to the profile owner directly on each post; there is no separate post-selection list.
- Archiving a post removes it from public pins automatically; deleting a post also deletes its pin records.

## Resilience

- Pin saving validates the session, ObjectIds, duplicate entries, the three-post limit, ownership, and archive state.
- Pin updates replace the ordered set in one database transaction, avoiding partial ordering on failed requests.
- Missing, stale, or deleted pin records are ignored safely, while the normal profile feed remains available.
- Pin and normal-feed queries fail independently and provide localized recovery messages instead of breaking the profile page.
- Protected navigation now degrades safely during a temporary Prisma/Atlas outage: unread counters fall back to zero and profile initialization presents a recovery screen instead of a framework error.

## Deployment

- Regenerate Prisma Client after deploying the `ProfilePinnedPost` schema.
- Android package metadata now uses version code 82 and version name 0.1.72.
- The repository release manifest points Web, Android, and Desktop update checks to the matching 0.1.72 APK and EXE.
