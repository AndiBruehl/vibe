# VIBE 0.5.4 — VIBE Glide

Date: 2026-10-26

Status: Web release.

VIBE Glide is a playable one-touch flight game in the Flappy Bird style. The transparent VIBE logo is the flying character. Tap, click, press Space, or press ↑ to flap through the obstacle gaps. Cleared gaps increase the score; the flight gets faster and the gaps narrow as the run continues. Colliding with a pipe, the ceiling, or the floor ends the run.

The game includes pause and restart controls, keyboard instructions in the animated help orb, a responsive playfield, Dark and Light theme colors, and an optional device-local best score. The flight remains playable if browser storage is blocked or full, and a window-resize fallback supports browsers without ResizeObserver. The logo has a simple visual fallback if its image cannot load. The Games hub marks all four games as playable.
