# VIBE 0.4.5 - Authentication UX polish

Local preparation, 2026-10-09. Not pushed or deployed.

- Web sign-in and linking notices now state whether cancellation, expiry, provider conflicts or callback errors changed the account.
- Web linking retry messages explain that the current session remains active and that retrying from the same page creates a fresh attempt.
- Android login, linking and connection recovery messages now distinguish cancelled attempts, expired attempts, temporary backend failures and preserved local sessions.
- Desktop startup and recovery errors now clarify that app recovery failures do not change the server-side VIBE account.
- Web development version and changelog are 0.4.5. Published APK/EXE metadata and native versions remain 0.4.1; no new installer was built.
