# VIBE 0.5.0 🛡️ — Native release readiness prep

Release date: 2026-10-09. Local development step; not deployed.

## Prepared now

- Web package metadata and visible app version now identify the local release train as 0.5.0.
- The visible beta flair changed to 🛡️ to mark the signing, integrity and native-update milestone.
- Android package metadata is prepared for 0.5.0 with versionCode 100.
- Desktop package metadata is prepared for 0.5.0.
- Added an automated native release readiness guard so the repository can distinguish prepared package metadata from accepted published artifacts.

## Intentionally still pinned

- `public/releases/latest.json` still points to accepted Android and Windows 0.4.1 artifacts.
- `public/releases/latest.sig.example.json` remains an unsigned placeholder.
- No private signing keys, keystores, certificates or passwords were created or committed.

## Required before publishing 0.5.0 native artifacts

- Build the exact 0.5.0 APK and EXE artifacts.
- Record SHA-256 and byte-size metadata for those exact files.
- Generate a real detached Ed25519 release-metadata signature with a protected private key stored outside the repository.
- Enforce signature verification in the installed Android and Desktop update paths.
- Run installed-device acceptance for login, linking, update discovery, integrity mismatch recovery, retry behavior, browser fallback and session preservation.
- Attach external evidence for production signing, GitGuardian closure and device acceptance.

Native APK/EXE downloads remain at 0.4.1 until those gates are complete.
