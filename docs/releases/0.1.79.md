# VIBE 0.1.79

## Video posters

- Let members upload an optional custom image poster for every video in a post.
- Add a time-slider frame editor so members can save a selected frame from a new or existing video as its poster.
- Save posters alongside each post media item and use them wherever that video is previewed.
- For videos without a custom poster, seek to the three-second frame after metadata loads.
- Use the middle of short videos as a safe fallback preview frame.
- Add a visible play marker to video previews in feeds, post detail, topics, browse, search, and shared messages.
- Fall back to a custom poster upload when browser or source restrictions prevent a frame export.

## Badge visibility correction

- Restrict curated badges to profile headers.
- Keep protected Admin and Verified statuses visible wherever a member name appears.
- Redesign the admin badge controls into explicit profile-only Award and Remove actions, without repeating curated badges in the account heading.
- Place the video play marker in the upper-left corner of each paused preview.
