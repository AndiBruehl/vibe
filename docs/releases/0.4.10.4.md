# VIBE 0.4.10.4 - Quick settings exit animation

Release date: 2026-10-09. Local development step; not deployed.

- Quick Settings now plays a reverse of the existing enter animation before the panel is removed.
- Auto-close, theme/language action close, outside-click close and navigation close all use the same animated close path.
- Added regression coverage that verifies the exit class appears before unmount and that the CSS contains the reverse motion.

Web development version and changelog are 0.4.10.4. Native APK/EXE downloads remain pinned to accepted 0.4.1 artifacts.
